Retail Sales Performance Dashboard

TOOLS USED

Excel, SQL, Power BI

OBJECTIVE

To analyse retail sales data and identify key insights related to revenue, profit, product, performance, and regional trends

KEY QUESTIONS

which product generated the most revenue?

which region perform best?

which category is most profitable?

how do discounts affect profit?

DATA CLEANING

removed duplicates

standardised data formats

created calculated fields(profit, margin, month-year)

KEY INSIGHTS

technology category generated highest revenue.

west region was top performer

some products generated high sales but negative profit

discounts reduced profitability in several cases
